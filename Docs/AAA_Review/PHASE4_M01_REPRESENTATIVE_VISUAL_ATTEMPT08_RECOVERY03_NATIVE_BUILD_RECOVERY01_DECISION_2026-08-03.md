# Recovery03 Native Build Recovery01 decision

The original Recovery03 plugin and Native Build Attempt01 remain immutable.
Recovery01 uses a new disabled-by-default editor plugin:
`SkyguardRecovery03NativeRecovery01`.

The new module owns the complete proof through `FTSTicker`. It is inert unless
the contract ID, one-shot authorization token, exact map, and exact fresh output
namespace all match. All immutable input hashes, map/RHI/landscape/material
conditions are checked before the output namespace is created.

The build supervisor invokes the installed native `AutomationTool.exe` directly.
This removes the failed `cmd.exe` wrapper from exit-code authority. The future
package root is `D:\SG52R03B02`; it remains absent during this gate.

No Unreal, Blender, build, capture, import, promotion, integration, or packaging
process is authorized by this design gate.
