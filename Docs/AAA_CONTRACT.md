# Skyguard52 AAA Goal Contract

## Product
Ukrainian Yak-52 open-cockpit backseat gunner vs Shahed drones over coastal city.
Unreal Engine 5.8 project: unreal/Skyguard52

## Non-negotiable quality bar
Compare against modern AAA open-world / combat reference quality:
- MSFS 2020/2024 cockpit + atmosphere fidelity
- Battlefield / Call of Duty weapon ADS tactile fidelity
- Ghost of Tsushima / RDR2 environmental material richness (as reference for nature/coast; adapt to Black Sea coastal city)
- Not "good for indie" — only pass if harsh critic would pick Skyguard frames in a blind A/B against those references for the specific subsystem under review.

## Current baseline (FAIL vs AAA)
- BasicShapes only (cube/plane/cone)
- Constant-color materials
- Empty Blueprint shells (no ADS/fire/drone AI graphs)
- Minimal lighting defaults
- No Nanite hero meshes, no Water system, no Niagara combat FX library, no MetaSounds package yet

## Workstreams
1. Rendering & atmosphere (Lumen, VSM, sky/atmosphere, exposure, post)
2. World: ocean, beach, city, roads, set dressing density
3. Cockpit / rifle / hand / ADS / ballistics feel
4. Drones, destruction, VFX, audio
5. Harsh AAA critic: screenshots + blind compare notes; reject until wowed

## Evidence required per pass
- Saved map/assets on disk
- Screenshot(s) under unreal/Skyguard52/Saved/Screenshots or Docs/AAA_Review
- Critic writeup with fail reasons or pass
